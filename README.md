# Simulados de Engenharia de Software e Projeto de Software

Site estático em HTML, CSS e JavaScript para estudar duas provas da faculdade.

## Funcionalidades

- Simulados por disciplina.
- Treino com correção imediata.
- Simulado de prova com correção ao finalizar.
- Treino por assunto.
- Refazer erros e dificuldades.
- Revisão rápida por matéria.
- Histórico e progresso salvos no navegador com `localStorage`.
- Modo claro e escuro.

## Publicação

Projeto compatível com GitHub Pages, sem backend.
